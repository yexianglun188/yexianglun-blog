## 你好，我是 yexianglun

一名在读学生，技术方向主攻 **Java 后端**，平时也折腾前端，把学到的东西做成真正跑得起来的东西。

写博客对我来说有两层意义：一是把踩过的坑沉淀下来，二是给自己攒一份拿得出手的作品。

## 关于 yexianglun

**yexianglun** 取自 **叶湘伦**——周杰伦自导自演的电影《不能说的秘密》里，那个弹钢琴、会写曲子的男主角。

我很喜欢这部电影，喜欢它把音乐、青春和一点遗憾揉在一起的样子，所以借主角的名字当作自己的网名和站名。

站内几乎没有「功能介绍」的必要，因为想玩的都有、想看的都有。简单说说它有什么：

### 内容

- **文章** — 分类、标签、全文搜索，正文带代码高亮与目录导航
- **小说** — 支持在线阅读、按章跳转，附搜索
- **说说** — 短动态，随手记录
- **时间轴** — 按时间顺序串起站点内容
- **照片墙** — 相册式浏览，支持灯箱查看
- **书签** — 收藏整理
- **留言板** — 访客可匿名留言

### 玩法

- **工具箱** — 30+ 小工具：智能搜索、全网热榜、天气、豆瓣榜单、GitHub 查询、计算器、二维码、进制换算、日历、快递查询、随机图片……日常用得上的基本都在
- **小花园** — 十来个纯前端的小实验：烟花、星空、雨、粒子、排序可视化、Python 沙盒、二维码生成……
- **音乐播放器** — 默认走**酷我音乐**搜歌（也能切网易云），播放 320k MP3，带歌词滚动与全屏沉浸歌词
- **彩蛋** — 散落在站里的隐藏小惊喜，收集齐有徽章
- **隐藏页面** — 摩斯密码解锁的情书页

### 后台

- 文章 / 分类 / 标签 / 评论 / 留言 / 说说 / 相册 / 照片 / 书签 / 项目 / 友情链接 全模块管理
- 音乐管理、访客记录、站点配置、用户与权限、仪表盘数据看板

> 技术栈：Next.js · TypeScript · Tailwind CSS · FastAPI · SQLModel · PostgreSQL
